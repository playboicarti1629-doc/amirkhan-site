# Настройка базы данных и публикация

Сайт — статический (GitHub Pages), поэтому отзывы хранятся во внешней базе **Supabase** (бесплатный тариф).

## 1. Создайте проект Supabase
1. Зайдите на https://supabase.com → **New project** (имя любое, пароль базы сохраните).
2. Дождитесь, пока проект создастся.

## 2. Создайте таблицу и правила доступа
1. Откройте файл `supabase/setup.sql` в VS Code.
2. Найдите строку с `ВАША_ПОЧТА@example.com` и впишите свою настоящую почту (ту, с которой будете входить в админку).
3. В Supabase: **SQL Editor → New query**, вставьте весь скрипт, нажмите **Run**.
   Скрипт создаёт таблицу `reviews`, ограничивает доступ (посетители могут только добавлять отзывы, читать их без почты, а менять и удалять может только владелец) и добавляет 5 тестовых записей.

## 3. Создайте аккаунт владельца
1. **Authentication → Users → Add user → Create new user**: ваша почта (та же, что в скрипте) и пароль, отметьте «Auto Confirm User».
2. **Authentication → Sign In / Providers**: отключите **Allow new users to sign up**, чтобы никто посторонний не мог зарегистрироваться.

## 4. Подключите сайт к базе
1. **Project Settings → API**: скопируйте **Project URL** и ключ **anon public**.
2. Вставьте их в `js/config.js`:
   ```js
   window.SITE_CONFIG = {
     SUPABASE_URL: 'https://xxxx.supabase.co',
     SUPABASE_ANON_KEY: 'eyJ...'
   };
   ```
   Ключ `anon public` можно публиковать: защиту обеспечивают правила из `setup.sql`. Ключ `service_role` в сайт вставлять нельзя.

## 5. Публикация
```
git add .
git commit -m "Итоговая версия портфолио"
git push
```
GitHub Pages обновит сайт через 1–2 минуты. Проверьте https://playboicarti1629-doc.github.io/amirkhan-site/ с телефона и компьютера.

## 6. Проверка
- Страница «Отзывы»: отправьте отзыв, он должен появиться в списке, форма очистится.
- `admin.html`: войдите, попробуйте добавить, изменить и удалить запись.
- Почта посетителей нигде, кроме админ-панели, не видна.
