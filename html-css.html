HTML, CSS и JavaScript

Технологии сайта

Сайт написан на чистых HTML, CSS и JavaScript без конструкторов. Разметка, стили и скрипты лежат в отдельных файлах: страницы *.html, стили css/styles.css, скрипты в папке js/. Данные отзывов хранятся в базе Supabase. Ниже — 16 групп HTML-элементов, 12 CSS-свойств и 6 функций JavaScript с кусочками кода из самого сайта.

CSS-свойства

display: flex

Располагает элементы в строку; на нём построено меню.

Как повлияло на сайт: Пункты меню стоят в одну строку, а на узком экране прячутся за кнопку.

.site-nav { display: flex; flex-wrap: nowrap; gap: 6px 15px; margin: 0; padding: 0; }

display: grid

Делит блок на колонки; нужен для сетки карточек.

Как повлияло на сайт: Карточки разделов стоят в три колонки, а на узких экранах — в две и в одну.

.card-grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 24px; margin: 0 0 40px; }

box-shadow

Рисует тень вокруг блока.

Как повлияло на сайт: Уведомление отбрасывает мягкую тень и выделяется на странице.

box-shadow: 0 8px 30px rgba(0, 0, 0, 0.4);

border

Задаёт рамку элемента.

Как повлияло на сайт: Тонкая тёмная рамка отделяет карточки от фона, не перегружая страницу.

border: 1px solid var(--border);

transition и transform

Плавно меняют положение элемента при наведении.

Как повлияло на сайт: Карточка раздела приподнимается при наведении — это обратная связь для пользователя.

transition: transform 0.3s ease, border-color 0.3s, background 0.3s;
.topic-card:hover { transform: translateY(-6px); border-color: var(--border-strong); background: var(--bg-hover); }

Пользовательские свойства (--)

Хранят значения, которые можно переиспользовать, в том числе для светлой темы.

Как повлияло на сайт: Цвета объявлены один раз; светлая тема просто подменяет их.

--accent: #ffcc00;
[data-theme="light"] {
  color-scheme: light;
  --bg: #f6f4ee;

clamp()

Ограничивает размер значением «минимум — желаемое — максимум».

Как повлияло на сайт: Заголовок страницы плавно становится больше или меньше вместе с шириной окна.

font-size: clamp(2.2rem, 6vw, 4.2rem);

@media

Применяет правила только при нужных условиях, например на узком экране.

Как повлияло на сайт: На телефоне меняются отступы и размер шрифта, а карточки встают в одну колонку.

@media (max-width: 700px) {
  body { font-size: 15px; }

position: fixed

Закрепляет элемент в одном месте экрана.

Как повлияло на сайт: Верхняя панель с меню остаётся на месте, когда страница прокручивается.

.topbar {
  position: fixed;
  top: 0;

overflow-x

Управляет тем, что происходит с содержимым, не помещающимся по ширине.

Как повлияло на сайт: Широкая таблица в админ-панели прокручивается, а не ломает страницу.

.admin-table-wrap { overflow-x: auto; margin: 0 0 30px; }

radial-gradient

Рисует фон из плавного цветового перехода.

Как повлияло на сайт: Фон главного экрана — мягкие цветные пятна, обычных картинок нет.

radial-gradient(ellipse at 70% 40%, var(--glow-1), transparent 50%),

text-transform

Меняет регистр букв без изменения текста в HTML.

Как повлияло на сайт: Главный заголовок отображается прописными буквами.

font-weight: 700;
  line-height: 0.95;
  letter-spacing: 0.03em;
  text-transform: uppercase;

JavaScript и интерактивность

Переключение светлой и тёмной темы

Кнопка в верхней панели меняет атрибут data-theme у страницы, а выбор сохраняется в браузере.

document.documentElement.setAttribute('data-theme', theme);

Поиск работ по названию и тексту

Скрывает карточки, где нет введённой фразы, подсвечивает совпадения и показывает счётчик.

card.hidden = !match;

Показ и скрытие содержимого карточек

Кнопки «−/+» и «Свернуть все» меняют состояние карточек.

card.classList.toggle('collapsed', collapsed);

Окно с увеличенным изображением

Нажатие на схему или скриншот открывает его в модальном окне.

dlg.showModal();

Галерея ракурсов модели

Миниатюры переключают главное изображение; работают и стрелки на клавиатуре.

main.src = src;

Форма отзывов с проверкой и базой данных

Проверяет поля, сохраняет отзыв в Supabase, показывает уведомление и очищает форму.

window.DB.client.from('reviews').insert([result.clean])
