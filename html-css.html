Технологии сайта

Сайт написан на чистых HTML, CSS и JavaScript без конструкторов. Разметка, стили и скрипты лежат в отдельных файлах: страницы *.html, стили css/styles.css, скрипты в папке js/. Данные отзывов хранятся в базе Supabase. Ниже — 16 групп HTML-элементов, 12 CSS-свойств и 6 функций JavaScript с кусочками кода из самого сайта.

CSS-свойства

display: flex

Располагает элементы в строку с переносом; на нём построено меню.

Как повлияло на сайт: Пункты меню выстраиваются в центре, а на узком экране переносятся на новую строку.

.site-nav {
  display: flex;
  flex-wrap: wrap;
  justify-content: center;
  gap: 11px;

display: grid

Делит блок на колонки; нужен для адаптивной сетки карточек.

Как повлияло на сайт: Карточки разделов сами подбирают число колонок под ширину экрана.

.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  gap: 20px;

box-shadow

Рисует тень; здесь — жёсткая «нео-брутальная» тень без размытия.

Как повлияло на сайт: Карточки и кнопки выглядят приподнятыми над страницей.

--shadow-small: 4px 4px 0 var(--ink);
box-shadow: var(--shadow-small);

border

Задаёт рамку элемента.

Как повлияло на сайт: Толстая чёрная рамка стала главной чертой стиля и отделяет блоки друг от друга.

--line: 3px solid var(--ink);
border: var(--line);

transition и transform

Плавно меняют положение элемента при наведении.

Как повлияло на сайт: Карточка сдвигается вверх-влево при наведении — это обратная связь для пользователя.

transition: transform .12s ease, box-shadow .12s ease;
.entry-card:hover { transform: translate(-2px, -2px); box-shadow: 6px 6px 0 var(--ink); }

Пользовательские свойства (--)

Хранят значения, которые можно переиспользовать, в том числе для тёмной темы.

Как повлияло на сайт: Цвета объявлены один раз; тёмная тема просто подменяет их.

--yellow: #FFDE59;
[data-theme="dark"] {
  color-scheme: dark;
  --paper: #15161a;

clamp()

Ограничивает размер значением «минимум — желаемое — максимум».

Как повлияло на сайт: Заголовок плавно становится больше или меньше вместе с шириной окна.

font-size: clamp(25px, 4vw, 42px);

@media

Применяет правила только при нужных условиях, например на узком экране.

Как повлияло на сайт: Для телефонов меняются отступы и размер шрифта.

@media (max-width: 700px) {
  body { padding: 18px 12px 34px; font-size: 15px; }

position: absolute

Помещает элемент в заданное место внутри родителя.

Как повлияло на сайт: Кнопка смены темы закреплена в правом верхнем углу шапки.

.theme-toggle {
  position: absolute;
  top: 12px;
  right: 12px;

overflow-x

Управляет тем, что происходит с содержимым, не помещающимся по ширине.

Как повлияло на сайт: Широкая таблица в админ-панели прокручивается, а не ломает страницу.

.admin-table-wrap { overflow-x: auto; margin: 0 0 30px; }

background-image

Рисует фон-картинку или градиент.

Как повлияло на сайт: Фон страницы — точечная сетка из радиального градиента, без картинок.

background-image: radial-gradient(var(--dot) 0.8px, transparent 0.8px);
  background-size: 17px 17px;

text-transform

Меняет регистр букв без изменения текста в HTML.

Как повлияло на сайт: Главный заголовок отображается прописными буквами.

font-weight: 900;
  letter-spacing: -.04em;
  text-transform: uppercase;

JavaScript и интерактивность

Переключение светлой и тёмной темы

Кнопка в шапке меняет атрибут data-theme у страницы, а выбор сохраняется в браузере.

document.documentElement.setAttribute('data-theme', theme);

Поиск работ по названию и тексту

Скрывает карточки, где нет введённой фразы, подсвечивает совпадения и показывает счётчик.

card.hidden = !match;

Показ и скрытие содержимого карточек

Кнопки «−/+» и «Свернуть все» меняют состояние карточек.

card.classList.toggle('collapsed', collapsed);

Окно с увеличенным изображением

Нажатие на схему или скриншот открывает его в модальном окне.

dlg.showModal();

Галерея ракурсов модели

Миниатюры переключают главное изображение; работают и стрелки на клавиатуре.

main.src = src;

Форма отзывов с проверкой и базой данных

Проверяет поля, сохраняет отзыв в Supabase, показывает уведомление и очищает форму.

window.DB.client.from('reviews').insert([result.clean])
