Для чего это портфолио

Это учебное портфолио собирает в одном месте мои результаты обучения: практические работы по информатике, 3D-модели из Blender, прототипы интерфейсов из Figma и сам сайт, написанный на HTML, CSS и JavaScript. Оно показывает, чему я научился, и помогает быстро найти нужные материалы по теме. Через форму в разделе «Отзывы» можно оставить мнение о работе — оно сохранится в базе данных.
